# Démonstration ARMS

[Lire ou télécharger la vidéo](arms-demo.mp4) : 1 min 21, muette, avec annotations françaises.

[Support PDF de trois diapositives](ARMS-3-diapositives.pdf).

[Projet vidéo reproductible](projet-demo.zip).

La capture montre le run réel `2026-11-12T15-15-13-789Z`, puis les résultats, l’architecture, les preuves transactionnelles et la matrice réglementaire. Le montage utilise les captures horodatées de l’interface locale, avec des coupes de navigation entre les sections. Chaque section conserve sa durée réelle, sans accélération. Toutes les données sont synthétiques.

Les chiffres de référence viennent des outils et du rapport JSON. Les commentaires du modèle léger sont des brouillons non validés. Ce laboratoire ne constitue ni un audit de BNP Paribas ni une certification réglementaire.

Vérification : décodage des 1219 images, lecture navigateur jusqu’à 81,27 s, neuf sections inspectées et PDF de trois pages rendu et vérifié.
